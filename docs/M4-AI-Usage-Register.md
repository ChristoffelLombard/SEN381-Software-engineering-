# M4 AI Usage Register

| Date / phase | AI-assisted activity | Human verification required | Final treatment |
|---|---|---|---|
| M4 finalisation | Repository review, M4 structure and closure drafting | Compare every claim against the M4 brief, M1 PED, M3 recording and current GitHub files | Used as drafting/review assistance; repository evidence remains authoritative |
| M4 finalisation | RTM and scope-status drafting | Verify requirement wording and implementation paths against controlled artefacts | Statuses intentionally recorded as Met / Partial / Not Met based on evidence |
| M4 finalisation | Code review for lifecycle/configuration consistency | Human review and CI/build verification before merge | Findings recorded as limitations where repository evidence does not support M3 claims |

## Verification rule

AI assistance does not constitute repository approval, test execution, stakeholder evidence, lecturer approval or final sign-off. The team must review the final branch and accept the pull request before the work becomes the project baseline.
